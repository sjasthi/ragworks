 # RAGworks Retrieval-Augmented Generation (RAG) system.
## This README is for end users/actual users of this application
## This will give you a basic rundown on how to use it once its up and running, it'll be split into the roles of the User and Admin



# User
For users, it should be fairly straight foward
```
1. for testing purposes, the user's username and password are set to: user and user246
2. once that is entered, click login and you should be taken to the chat screen
3. you are now able to ask the bot questions, now for testing purposes we've added documents relating to Metropolitan State Unniversity
5. you can ask questions about the school and the bot will likely have answser, though the bot will answer with 'i do not know' in the event in doesn't have information
6. to logout, click the logout button at the top right of your screen, note that this will instantly log you out
```
That concludes the user side, moving onto


# Admin
Admin should also be straight forward

```
1. once again for testing purposes, the user and password are set to: admin and admin135
2. once entered correctly, click login and you'll be taken to the storage management screen
3. from here you will see the database's name, amount of documents, and total chunks used
4. to upload a file, you have to enter the full file path, something like "C:/../file.pdf"
5. you can upload pdf, pptx, txt, docx, and html files, you also have the option to replace/update a file if it's already in the database
6. for testing purposes there should be at least 27 files (once again relating to Metro State)
7. there is also a refresh button, this should refresh the list incase something seems wrong
8. once again, to to logout, click the logout button at the top right of your screen, note again, that this will instantly log you out
```

This concludes the End User README.
